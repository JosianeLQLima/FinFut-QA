# Casos de Teste

Esta pasta contém os casos de teste elaborados para validar as principais funcionalidades da aplicação **FinFut — Sistema de Controle Financeiro Pessoal**.

Os testes foram estruturados com base nos requisitos funcionais, regras de negócio e critérios de validação definidos para o projeto.

### Objetivo

Garantir que as funcionalidades da aplicação estejam funcionando conforme o esperado, identificando possíveis falhas antes da entrega.

### Cobertura dos testes

Os casos de teste abrangem:

* Login e autenticação;
* Cadastro de usuário;
* Cadastro de receitas;
* Cadastro de despesas;
* Contas a pagar;
* Contas a receber;
* Gerenciamento de movimentações;
* Resumo financeiro;
* Filtros;
* Validações de campos;
* Regras de negócio;
* Segurança e isolamento dos dados dos usuários.

Os casos de teste seguem uma estrutura padronizada contendo **ID, requisito, cenário, pré-condição, dados de teste, passos, resultado esperado, tipo de teste, prioridade, resultado da execução, evidência e observações**.
